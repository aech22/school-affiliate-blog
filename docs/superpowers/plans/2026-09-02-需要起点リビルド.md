# コドナビ 需要起点リビルド 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** コドナビを「教育訓練給付金を入口にした訴求型ブログ」に作り替え、検証済みの事実だけを使って隔日1本を自動公開できるようにする。

**Architecture:** 既存の「事実はデータファイル、LLMは文章だけ」という分離を本文にも拡張する。検証済みの制度事実を `src/data/facts.json` に置き、`generate.py` が生成した本文から金額・率の数値を抽出して台帳と照合し、台帳に無い数値が出たら記事を破棄する。記事は `scripts/queue.json` から1回1本だけ生成し、GitHub Actions が隔日で回す。

**Tech Stack:** Astro 5 / Tailwind 4（`@tailwindcss/typography` 導入済み）/ Python 3（`anthropic`・`PyYAML`）/ GitHub Actions

**Spec:** `docs/superpowers/specs/2026-09-02-需要起点リビルド-design.md`

## Global Constraints

- **Python は `python3`（システム）を使う。** リポジトリの `.venv` は `yaml` が入っておらず壊れている。`.venv/bin/python` を使わない
- **pytest は導入しない。** テストは `python3 scripts/test_gate.py` で走る素の `assert` スクリプトにする（既存リポジトリにテスト基盤が無く、依存を増やさない）
- **A8 の URL（`px.a8.net` / `www*.a8.net`）をブラウザで開かない。** 検証は `curl` / `grep` のみ
- **`main` に push しない。** 作業ブランチは `rebuild/demand-driven`。`main` への push は本番デプロイを起こすため、全タスク完了後にユーザーの指示を得てから
- **公開日（`date`）を遡らせない。** 既存記事の `date` は `_existing_publish_date()` が維持する
- **運営者表記は屋号「TODGE」のみ。**「株式会社TODGE」と書かない
- **断定的な最上級表現を書かない**（「最安」「絶対」「No.1」「必ず転職できる」）
- 検証済み事実の正本: `Obsidian/Projects/情報検証/factcheck/2026-09-02_学び支援制度_教育訓練給付金とリスキリング補助金.md`

### Task 2: 検証ゲート `gate.py`（TDD）

本文に台帳外の金額・率が混ざるのを構造的に防ぐ。

**ゲートの対象を金額と率に限る理由:** 「3つの観点」「2〜3社」「1年以内」まで照合対象にすると偽陽性で全記事が落ちる。景表法・ASP規約で実害が出るのは**金額と率**なので、そこに絞る。

**Files:**
- Create: `scripts/gate.py`
- Test: `scripts/test_gate.py`

**Interfaces:**
- Produces:
  - `normalize(token: str) -> str` — 表記ゆれを吸収する（カンマ除去、`％`→`%`）

  - `check(text: str, facts: list[dict], services: list[dict]) -> list[str]` — 許可集合に無いトークンの一覧を返す。空リストなら合格

```python
# scripts/gate.py — 本文に「台帳にない金額・率」が混ざっていないか検査する。
#
# なぜ金額と率だけを見るのか:
#   「3つの観点」「2〜3社」まで照合対象にすると偽陽性で全記事が落ちる。
#   景表法・ASP規約で実害が出るのは金額と率なので、そこに絞る。
from __future__ import annotations
import re

# 金額（円・万円）と率（%）だけを拾う。個数・社数・年数・日数は対象外。
_TOKEN = re.compile(r"\d[\d,]*(?:\.\d+)?\s*(?:万円|円|%|％)")


def normalize(token: str) -> str:
    """表記ゆれを吸収する。カンマを外し、全角％を半角に、空白を除く。"""
    return token.strip().replace(",", "").replace("％", "%").replace(" ", "").replace("　", "")


def extract_money_and_rate(text: str) -> list[str]:
    """本文から金額・率の表現を抽出して正規化して返す（重複は保持しない）。"""
    seen: list[str] = []
    for m in _TOKEN.findall(text or ""):
        n = normalize(m)
        if n not in seen:
            seen.append(n)
    return seen


def allowed_tokens(facts: list[dict], services: list[dict]) -> set[str]:
    """facts の numbers[] と services の priceNote から、本文に出してよい表現の集合を作る。"""
    allowed: set[str] = set()
    for f in facts or []:
        for n in f.get("numbers") or []:
            allowed.add(normalize(n))
    for s in services or []:
        allowed.update(extract_money_and_rate(s.get("priceNote") or ""))
    return allowed


def check(text: str, facts: list[dict], services: list[dict]) -> list[str]:
    """許可集合に無い金額・率の一覧を返す。空リストなら合格。"""
    allowed = allowed_tokens(facts, services)
    return [t for t in extract_money_and_rate(text) if t not in allowed]
```

def build_topic(topic: dict, today: str) -> tuple[dict | None, str, list[str]]:
    """(frontmatter, body, violations) を返す。violations が空でなければ破棄する。"""
    services = [BY_ID[i] for i in topic.get("serviceIds", []) if i in BY_ID]
    facts = [FACT_BY_ID[i] for i in topic.get("factIds", []) if i in FACT_BY_ID]
    if not services and not facts:
        print(f"[SKIP] {topic['slug']}: serviceId も factId も0件")
        return None, "", []
    prose = _llm_prose(services, topic["theme"], facts, topic.get("type", "compare"))
    body = (prose.get("body") or "").strip()

    # 検証ゲート: 本文・intro・outro を通して、台帳にない金額・率が無いか調べる
    checked_text = "\n".join([body, prose.get("intro", ""), prose.get("outro", "")])
    violations = gate_check(checked_text, facts, services)
    if violations:
        return None, "", violations

    items = prose.get("items", [])
    refs = []
    for i, s in enumerate(services):
        it = items[i] if i < len(items) else {}
        ref = {
            "id": s["id"],
            "rank": i + 1,
            "pros": (it.get("pros") or [])[:3],
            "cons": it.get("cons", ""),
            "target": it.get("target", ""),
        }
        refs.append({k: v for k, v in ref.items() if v not in (None, "", [])})
    path = OUT_DIR / f"{topic['slug']}.md"
    publish_date = _existing_publish_date(path) or today
    fm = {
        "title": topic["title"],
        "date": publish_date,
        "updated": today,
        "description": prose.get("description", ""),
        "category": topic.get("category", ""),
        "categorySlug": topic.get("categorySlug", ""),
        "type": topic.get("type", "compare"),
        "intro": prose.get("intro", ""),
        "outro": prose.get("outro", ""),
        "services": refs,
    }
    return {k: v for k, v in fm.items() if v not in (None, "")}, body, []

```python
def main() -> None:
    if not os.environ.get("ANTHROPIC_API_KEY"):
        sys.exit("ANTHROPIC_API_KEY が未設定です。環境変数に設定してから実行してください。")
    OUT_DIR.mkdir(parents=True, exist_ok=True)
    today = datetime.datetime.now(JST).date().isoformat()

    queue = json.loads(QUEUE_PATH.read_text(encoding="utf-8"))
    pending = queue["pending"]
    by_slug = {t["slug"]: t for t in TOPICS}

    item = next((x for x in pending if not x.get("blocked")), None)
    if item is None:
        print("キューに処理できる項目がありません。キーワード補充が必要です。")
        return

    topic = by_slug.get(item["slug"])
    if topic is None:
        print(f"[SKIP] {item['slug']}: topics.json に定義がありません")
        pending.remove(item)
        QUEUE_PATH.write_text(json.dumps(queue, ensure_ascii=False, indent=2) + "\n", encoding="utf-8")
        return

    try:
        fm, body, violations = build_topic(topic, today)
    except Exception as e:
        print(f"[ERROR] {item['slug']}: {type(e).__name__}: {e}")
        return

    if violations:
        item["failures"] = item.get("failures", 0) + 1
        item["lastViolations"] = violations
        print(f"[GATE] {item['slug']}: 未検証の数値 {violations}（{item['failures']}回目）")
        if item["failures"] >= MAX_FAILURES:
            item["blocked"] = True
            pending.remove(item)
            pending.append(item)
            print(f"[BLOCKED] {item['slug']}: {MAX_FAILURES}回連続で落ちたためキュー末尾へ送りました。"
                  f"facts.json に根拠を追加するか topics.json の theme を見直してください")
        QUEUE_PATH.write_text(json.dumps(queue, ensure_ascii=False, indent=2) + "\n", encoding="utf-8")
        return

    if not fm:
        print(f"[SKIP] {item['slug']}: 生成対象なし")
        return

    (OUT_DIR / f"{item['slug']}.md").write_text(to_markdown(fm, body), encoding="utf-8")
    pending.remove(item)
    QUEUE_PATH.write_text(json.dumps(queue, ensure_ascii=False, indent=2) + "\n", encoding="utf-8")
    print(f"generated -> {item['slug']}.md（本文{len(body)}字・{len(fm.get('services', []))}件）")
    print(f"残りキュー: {len([x for x in pending if not x.get('blocked')])}件")
```
